# Zen Habit for Android

> One small thing, every day.

Zen Habit 是一款简洁、安静的 Android 习惯追踪 App。它用月历、彩色主题和热力图记录每天的小小坚持，让习惯管理变得轻松而直观。

![Zen Habit Android calendar](.zenhabit-android-calendar.png)

## 下载

请打开本仓库的 GitHub **Releases** 页面，下载最新的正式版 APK：

```text
app-release.apk
```

这是正式签名版本，适合直接安装到 Android 手机使用。

## 安装方法

1. 在 Android 手机上下载 APK。
2. 打开下载的 APK 文件。
3. 如果系统提示“允许安装未知来源的应用”，请在设置中允许浏览器或文件管理器安装应用。
4. 返回安装页面，点击“安装”。
5. 安装完成后，打开 Zen Habit。

如果手机上已经安装旧版本，建议先在 App 内导出数据备份，再安装新版本。

## 主要功能

- 月历打卡：按月份查看每天的完成记录。
- 主题管理：为习惯设置名称、说明、图标和颜色。
- 文件夹整理：将主题归入健康、运动、生活、学习等文件夹。
- 批量打卡：长按日期，一次选择多个日期进行打卡或删除。
- 追踪热力图：按主题查看月度坚持情况。
- 环境声：内置竹雨、松涛、清风、远钟四种本地声景。
- 数据备份：导出或导入 JSON 文件，保存主题、文件夹和打卡记录。
- 双语界面：支持中文和 English。
- 大字号模式：支持标准、大、特大三种文字大小。

## 隐私与数据

- 不需要注册账号。
- 不需要登录或联网才能使用核心功能。
- 主题、文件夹和打卡记录默认保存在手机本地。
- 应用不提供云端同步。
- 可以通过“数据备份”导出 JSON 文件，并在需要时恢复。

请妥善保存导出的备份文件。卸载应用或清除应用数据可能会删除手机上的本地记录。

## 常见问题

### 为什么无法安装？

请确认：

- 手机系统为 Android 6.0 或更高版本；
- APK 下载完整，没有被浏览器中断；
- 已允许当前浏览器或文件管理器安装未知来源的应用；
- 手机中没有安装同包名但使用不同签名的旧版本。如果有，请先备份数据并卸载旧版本，再安装正式版。

### 安装后数据在哪里？

数据保存在 App 的本地存储中，不会自动上传到服务器。更换手机前，请先使用“导出 JSON”备份，然后在新手机中导入。

### 为什么背景声没有声音？

请检查手机媒体音量、静音模式和 App 内的音量设置。部分手机在静音或省电模式下会限制媒体播放。

### 如何反馈问题？

请在 GitHub 仓库的 **Issues** 页面提交问题，并尽量附上：

- 手机型号和 Android 版本；
- Zen Habit 版本号；
- 问题出现前的操作步骤；
- 截图或录屏；
- 是否可以稳定复现。
